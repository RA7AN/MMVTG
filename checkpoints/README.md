# Checkpoints

## Purpose

This directory is for storing and documenting released model checkpoints.

**Checkpoint files are not included in this repository due to size constraints.** They are hosted on huggingface.

## Expected Checkpoints

### Pretrained Checkpoint

- **File:** `mmvtg-pretrained-asr.ckpt`
- **Description:** Weakly-supervised ASR pretrained model
- **Source:** Generated by running `bash moment_detr/scripts/pretrain.sh`
- **Download:** [https://huggingface.co/ra7an/mmvtg/blob/main/mmvtg-pretrained-asr.ckpt](https://huggingface.co/ra7an/mmvtg/blob/main/mmvtg-pretrained-asr.ckpt)



### Fine-tuned Checkpoint

- **File:** `mmvtg-finetuned-qvhighlights.ckpt`
- **Description:** Model fine-tuned on QVHighlights
- **Source:** Generated by running `bash moment_detr/scripts/train.sh`
- **Download:** [https://huggingface.co/ra7an/mmvtg/blob/main/mmvtg-finetuned-qvhighlights.ckpt](https://huggingface.co/ra7an/mmvtg/blob/main/mmvtg-finetuned-qvhighlights.ckpt)



### Best Checkpoint

- **File:** `mvtg-best-val.ckpt`
- **Description:** Best performing checkpoint on validation set
- **Source:** Generated during fine-tuning with validation monitoring
- **Download:** [https://huggingface.co/ra7an/mmvtg/blob/main/mvtg-best-val.ckpt](https://huggingface.co/ra7an/mmvtg/blob/main/mvtg-best-val.ckpt)
