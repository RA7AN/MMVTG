# Configuration Files

## Purpose

This directory contains YAML configuration files for training, evaluation, and inference.

## Expected Configurations

- `pretrain.yaml` — Weakly-supervised ASR pretraining configuration
- `finetune.yaml` — QVHighlights fine-tuning configuration
- `evaluate.yaml` — Evaluation configuration
- `inference.yaml` — Inference configuration
- `deploy.yaml` — Deployment configuration
