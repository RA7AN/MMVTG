# Model Architecture

## Purpose

This document describes the model architecture used in MMVTG.

## Expected Contents

- Overview of Moment-DETR architecture (original work)
- MMVTG extensions and modifications
- Encoder and decoder specifications
- Feature extraction details (video, text, audio)
- Model variants and sizes

## Attribution

The core architecture is based on **Moment-DETR** by Lei et al. Our work extends Moment-DETR with:
1. Weakly-supervised ASR pretraining
2. FIR-grounded inference prompting

We do not claim ownership of the original Moment-DETR architecture.
